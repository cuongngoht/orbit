# 1.7.0 baseline audit — autonomous QA and plan coverage

**What this is.** The audit that comes before any autonomy is added (the brief's PR0). Each row
below states an invariant and the smallest input that breaks it. It gives what the engine did at
the baseline, what the contract says it must do, the public path a consumer reaches it through,
and the test that now holds it.

**Baseline.**
- Branch `Release-1.7.0`, HEAD `f15b66e`, whose tree is identical to `ebe0409` (1.6.4).
- Node 24.
- `node --test`: 1506 tests, 1504 pass, 2 skipped.
- Five Lines: 0 findings.
- `ship.mjs`: shippable at 1.6.4.

**Method.**
- Every regression test was written first and run against the unmodified module.
- The failure it printed is quoted in the table.
- Expectations come from the contract (README §4.11, §5, AGENTS.md and the brief), never from the
  output of the function under test.
- The tests are `test/autonomous-qa-audit.test.mjs` and `test/qa-coverage-audit.test.mjs`.
  They drive the same entry points the CLIs call:
  - `begin · act · checkData · analyse`, from `src/investigation/index.mjs`, which is exactly what
    `cli/autonomous-qa.mjs` calls;
  - `coverageModel · traceRows · coverageView`, which is what `qa-plan coverage` renders;
  - `runCase`, which is what `cli/run-case.mjs` calls;
  - the CLI itself, spawned, for C18.

## Looked at, and not defects
- **The action budget counts every action record,** including reproduction replays and security `goto`s. This is by design: a replay is an action, and it costs what an action costs.
- **Gates read the current settings rather than the snapshot in `created`.** This is by design: a person raising a limit takes effect at once.
- **`settings set` without `--revision` uses the revision it just read.** That is a person's CLI convenience. Orbit Control always sends the revision it showed.
- **`home/Delete` is refused for its missing selector before the destructive gate speaks.** Both refuse, so only the message order differs.

## Gaps closed after the fixes (not defects of what exists)
These are the brief's PR2–PR4 prerequisites.
- **A call-only case cannot run headless.** It needs a final `report` step (which evaluates in the page), the session gate always runs, and FAIL evidence always asks the browser.
- **A plan with no screen fails `plan-check`,** and agent-authored plans have nowhere to go.
- **DEADLINE counts from `meta.at`,** so a resumed investigation would be Blocked forever.
- **Knowledge accepts only tracked paths through its public door.** An engine-stamped reference needs a door of its own.
