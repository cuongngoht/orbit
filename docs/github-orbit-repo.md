# Repository: cuongngoht/orbit

Canonical public home for Orbit.

```bash
git clone https://github.com/cuongngoht/orbit.git
cd orbit
npm test
```

Install in Claude Code:

```bash
/plugin marketplace add cuongngoht/orbit
/plugin install orbit@orbit
```

Machine store defaults to `~/.orbit/projects/`; override with `ORBIT_STORE_DIR`.
