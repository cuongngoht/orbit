Written 2026-11-07 for whoever continues the release. Everything below is on GitHub; nothing lives only in a
container. Read `CLAUDE.md` ("Shipping a release from Claude Code cloud") and `AGENTS.md` first.

## The owner's rules for this release

- Code is written and fixed by **Opus 5.5 at max effort**.
- Every benchmark run — pre-check, ship rows, new suites, arms — is **Sonnet 5.5 at medium effort**
  (`--model=claude-sonnet-5-5 --effort=medium`).
- A benchmark row that fails is diagnosed from its run room, the Orbit defect fixed with a regression test, and the row
  run again, without asking. Never loosen an acceptance rule, a case's truth, the verifier or `ship/policy.json`.
- The goal is to ship 0.5.0: SHIPPABLE, `ship.mjs --evidence` PUBLISHABLE on the pushed head, green CI, then merge the
  release PR to `main` and tag `v0.5.0` on the merge commit.
